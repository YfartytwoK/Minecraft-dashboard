1. Click **PC** in the sidebar
2. Click **Choose Server Folder** → pick the folder where your Minecraft server lives (where `server.jar` or `eula.txt` is)
3. Click **Choose Start File** → pick your `.bat` start script if you have one, or the `.jar` file itself (e.g. `paper.jar`, `server.jar`)
4. Click **Save Settings**
5. Go back to **Home** and click **Start Server**

That's it — the app will launch your server, show the console in **Logs**, track who's online in **Players**, and let you stop/restart from **Home**.

".bat" file is on youtube with a full tutorial.
